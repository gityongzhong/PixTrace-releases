# PixTrace · 去背景

> 纯本地推理的批量去背景工具。图片不经过任何网络，断网可用。

**只做两件事**：

1. **去掉背景**，输出带透明通道的 PNG
2. **换成纯色背景**（任意取色），用于证件照换底等场景

## 下载

前往 [Releases](../../releases/latest) 下载最新的 `PixTrace-X.Y.Z-portable.zip`，解压即可运行。

> 本仓库只存放安装包，不包含源代码。

## 特性

- **极简界面**：拖入图片 → 选背景 → 开始处理，没有多余选项
- **高精模型**：内置 isnet-general-use（DIS），发丝与复杂边缘干净
- **边缘去色染（defringe）**：自动反解边缘半透明像素的纯前景色，蓝底证件照换红底后**没有蓝边**
- **批量**：拖入文件夹即递归处理，任务列表实时显示状态与耗时
- **保存省心**：默认与原图同目录（文件名加 `-无背景` 后缀，不覆盖原图），也可另存到指定文件夹
- **零联网**：全部推理基于 ONNX Runtime CPU，无 PyTorch、无云 API、无额度限制
